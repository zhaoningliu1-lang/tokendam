Set up TokenDam Cloud

This creates the TokenDam GitHub App in your account, pre-configured to audit token cost on every PR. GitHub generates the private key & webhook secret for you — you don't fill in anything.

  1. Click the button → GitHub asks you to confirm creating TokenDam.
  2. Click Create GitHub App on GitHub's page.
  3. You'll land on a page showing the App ID, webhook secret, and private key — hand those to your assistant (or into Vercel) and Cloud goes live.

Creating for an organization instead? Add ?org=YOUR_ORG to this page's URL first.

# Uses GitHub's official App Manifest flow. TokenDam Cloud is served from tokendam.dev; the app only gets Pull requests (write), Contents (read), Metadata (read).
